## 1. 実施内容

計画書（Phase 0〜5）に沿って、原典 `spaceinvaders.py`（修正済み）を SDL2 を土台に C 言語へ移植した。

- src/main.c（145行）: SDL 初期化、イベント→Input 変換、60fps のメインループ、スモークテスト用の入力合成
- src/game.c（825行）/ game.h（127行）: 状態遷移（タイトル／プレイ／ラウンド間／ゲームオーバー）、自機・敵集団・弾・ミステリーシップ・トーチカ・爆発の更新と描画、当たり判定
- src/logic.c（203行）/ logic.h（73行）: 敵の台帳（生きている列・左右端・加算）、速度表、得点表、発射規則、トーチカ設計表。SDL 非依存
- src/assets.c（125行）/ assets.h（55行）: 画像20点・音10点・フォント（20/25/50）の読み込みと解放、文字描画
- tests/test_logic.c（180行）: logic の単体テスト
- 合計 1,733 行（計画の見込み 2,000〜2,500 行よりやや少なく収まった）

素材は原典リポジトリから必要な分だけを複写した（画像20点、音10点、フォント1点、計568KB）。新しい素材は作っていない。本家リポジトリ ~/workspace/space_invaders には変更を加えていない。commit/push はしていない。

## 2. 実装中に直した計画書の誤り

1. **ラウンド開始オフセットの解釈**: 計画書の初版は「timeOffset = 22000 × ROUND_NUM で出現が遅れる」と書いていた。実装前に原典で実測したところ、実際はタイマーの追いつきによる「速進」だった（ラウンド2以降、開始直後は毎フレーム移動ステップが走り、120フレームで約119ステップ。ラウンド1は9ステップ）。計画書の該当箇所は実測に基づく記述に訂正済みで、C版は原典の式（1フレーム最大1ステップ、`timer += moveTime`）のまま写した。
2. **トーチカの設計表の行数**: 計画書初版は「17行」としていたが、実測は16行（先頭の空行を含む）、1基あたり318セルだった。C版の表は原典の実データとセル単位で一致させ、テストで 318 を固定した。

## 3. 原典の癖の再現（主なもの）

- 自機の移動: キーを押している間 vx が +1 ずつ増え、位置は差の 1/3 ずつ寄る。Python の負数の床割り算により、左移動は切り上げ・右移動は切り捨てになる非対称もそのまま写した
- 敵集団の波状移動（ROW_counter の行だけが動き、残り4体以下で全員が動く）、moveNumber 初期値15、端の列の全滅で反対側の移動回数に +5 ずつ加算
- 敵の出現タイミング: 各敵の描画開始が timeOffset（行×-50＋列×120）だけずれる
- 速度表（update_speed の全段。1体で moveTime=2 かつ LEVEL=350、40体以下で LEVEL=400 を含む）と、敵生成時に LEVEL=700 に戻る癖
- ラウンド6以上では弾が残っていても3発が追加で撃たれる発射規則（規則自体は logic のテストで固定）
- ミステリーシップの25秒周期、出入りの音（音量0.1、4秒フェードアウト）、得点 {50,100,150,300} と点滅表示
- ゲームオーバーの文字が段階的に増える時間窓（専用タイマー基準。Python 版 F-5 の修正形を踏襲）
- BGM の4音（敵の移動間隔×3 の周期で循環）

置き換えたもの: 全域 `game` 参照 → Game 構造体のポインタ渡し。スプライトグループ → 固定長配列。地面ブロック4基分の重なり → 1本（等価）。発射音の重なり → 最後の音のみ（聞き分けできない差として明記）。

## 4. 環境の特記事項（この VM 固有）

この VM では SDL2 開発パッケージを apt で通常インストールできなかった。理由は、VM 側で入っている libzstd1 が専用ビルド版（版数に +hatch1）のため、依存先の libzstd-dev が求める通常版と版数が一致せず、依存解決が止まること。システムのライブラリには手を入れず、deb パッケージをダウンロードして ~/workspace/space_invaders_c/.sdl/ に展開し、その場所を指定して検証ビルドした。通常の環境（Satoru の手元を含む）では apt でのインストールと `make` がそのまま使える想定で、Makefile は標準の pkg-config 方式のままにしてある。`.sdl/` とビルド済み実行ファイルは検証用として残置した（README にも明記）。
